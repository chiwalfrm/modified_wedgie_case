# modified_wedgie_case
Modification to the wedgie case

With regard to: https://github.com/clawdbotatg/wedgie-dev

**FIRST MODIFICATION**

I had a lot of trouble keeping the wires of the STEMMA QT / Qwiic cable (4-pin JST-SH plug) in the holes despite using electrical tape, so I came up with a better design.

First, get stacking headers ($1.50) from Adafruit: https://www.adafruit.com/product/5582

You can use these headers to 'jam' in the wires. Because there are separate headers for each side of the display, you can do one side at a time, this "locks in" the two wires on that side. In addition, to make the wire stronger, I tinned it with solder.

This makes the build 12mm taller, so I modified the case design to be 12mm higher. Only the two sides of the base, and the four sides of the top have to be extended this way.

I believe this is much better than using electrical tape in the original design which never worked for me (probably a skills issue though).

**SECOND MODIFICATION**

I also had trouble with the joystick because the socket is too small so I made it slightly larger (2.0 mm vs 1.9 mm).  Also when I push the joystick in one direction, I can see the opening underneath so I made the round disc slightly larger at 11 mm vs 10 mm.
